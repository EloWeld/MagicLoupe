# Changelog

## 0.2.0

Color Lens skin and a hole that stays a hole.

- Glass and Color Lens skins, switched from the header, settings, and menu bar
- Color Lens is new-retro: pixel wordmark, prism frame, system Translate icon in white
- The framed area is a transparent punch-through again; Glass no longer dims it
- OpenRouter key is stored so ad-hoc rebuilds do not re-prompt for the login keychain password

## 0.1.0

First public build.

- Menu-bar loupe with a floating frame and glass overlay
- Vision OCR of the framed region, translation through OpenRouter
- Screen Recording permission wall, API key stored in Keychain
- Manual and automatic modes, ten target languages
- Click-through when unlocked; copy the translation when locked
